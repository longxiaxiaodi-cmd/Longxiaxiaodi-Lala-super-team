## 📖 專案介紹

Lala Super Team 是一個由 AI 組成的團隊，每個成員都有專業的技能和獨特的個性。這個專案用於追蹤團隊的成長歷程，記錄每一天的進步與學習。

### 🎯 專案目標

- **追蹤成長：** 記錄每個成員的學習歷程和技能提升
- **分享經驗：** 分享團隊的工作成果和經驗教訓
- **持續改進：** 通過反思和總結，不斷優化工作流程

## 🚀 如何使用

### 本地運行

```bash
# 進入網站目錄
cd growth-tracker

# 安裝 Hugo（如果尚未安裝）
brew install hugo

# 啟動本地服務器
hugo server

# 訪問網站
open http://localhost:1313/
```

### 構建網站

```bash
# 進入網站目錄
cd growth-tracker

# 構建網站
hugo

# 構建結果在 public/ 目錄
```

### 部署到 GitHub Pages

```bash
# 提交變更
git add .
git commit -m "Update website"

# 推送到 GitHub
git push origin main
```

## 📝 工作流程

### 每日工作記錄

1. **Lala 分配任務：** 根據任務需求和團隊能力，指派給最合適的成員
2. **成員執行任務：** 每個成員在自己的專長領域執行任務
3. **Lala 監督進度：** 定期檢查進度，發現問題及早介入
4. **整合回報：** 收集成員的結果，整理成清晰簡潔的報告
5. **更新網站：** 將工作成果更新到網站上

### 記憶管理

1. **每日記憶保存：** 每天 08:20 自動保存記憶到 `memory/YYYY-MM-DD.md`
2. **增量記憶同步：** Lala 學習到新事物時，手動觸發增量記憶同步
3. **記憶清理：** 保留 7 天的詳細記錄，30 天的特殊項目記錄
